# 多边形填充演示

这是一个基于 C++ 和 EasyX 的计算机图形学示例。在同一个多边形上演示种子填充和扫描线填充。

## 构建与运行

1. 安装支持 MSVC v145 的 Visual Studio，并启用「使用 C++ 的桌面开发」和 Windows SDK。
2. 安装 [EasyX](https://easyx.cn/) 到对应的 Visual Studio 工具链。
3. 打开 `tuxing_fuxing.slnx`，选择 `Debug | x64`，按 `Ctrl+F5` 运行。

## 操作

| 按键 | 功能 |
| --- | --- |
| `1` | 种子填充，显示为橙色 |
| `2` | 扫描线填充，显示为蓝色 |
| `R` | 清除填充，恢复多边形轮廓 |
| `Esc` | 退出 |

`main.cpp` 包含程序入口、两种填充算法和快捷键处理。扫描线填充用边表（ET）记录边的起始扫描线，用活动边表（AET）维护当前交点，按横坐标排序后成对绘制填充区间。
